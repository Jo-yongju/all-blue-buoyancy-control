# 연결과 시험

NUCLEO-G431RB 시험 보드 기준입니다.

| STM32 핀 | 연결 | 역할 |
|---|---|---|
| PB6 | MDD10A PWM1 | TIM4 CH1 |
| PC4 | MDD10A DIR1 | 모터 1 방향 |
| PB9 | MDD10A PWM2 | TIM4 CH4 |
| PC7 | MDD10A DIR2 | 모터 2 방향 |
| PA0 | 센서 1 가변접점 | 모터 1 위치 |
| PA1 | 센서 2 가변접점 | 모터 2 위치 |
| 3V3 / GND | 두 센서 저항 양끝 | 센서 전원 |
| GND | MDD10A 신호 GND | 공통 기준 |

배터리는 MDD10A B+ / B−에, 모터는 M1A/M1B와 M2A/M2B에 연결합니다. 모터 전원과 센서 전원은 구분합니다.

현재 배선에서 음수 JOG는 흡입·ADC 증가, 양수 JOG는 배출·ADC 감소 방향입니다. 모터선을 바꾸면 방향도 바뀝니다.

| 목표 | 모터 1 / 센서 1 | 모터 2 / 센서 2 |
|---|---:|---:|
| UP | 0 | 0 |
| HOVER | 522 ±5 | 529 ±5 |
| DOWN | 4095 | 4095 |

ADC 0과 4095는 포화 구간입니다. 기계적 끝점이나 정확한 물량을 의미하지 않으므로 설치된 센서와 피스톤의 이동 범위를 확인해야 합니다.

- `Start-Position.ps1`: 모터 선택 후 개별 목표 이동
- `Test-MDD10A-DualPosition.ps1`: 두 모듈 동시 목표 이동
- `Test-MDD10A.ps1`: 방향·PWM·시간을 지정하는 JOG

COM 액세스가 거부되면 다른 터미널의 포트 점유를 확인합니다. 모터는 회전하지만 센서가 움직이지 않으면 기어·너트·센서 연결을 먼저 확인합니다.
