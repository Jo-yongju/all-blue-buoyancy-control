슬라이더 실측 보정 반영 — 2026-11-09

대상: water_robot_117/updown_dir_control (NUCLEO-G431RB)
사용자가 제공한 사용 이동 범위: 58.48mm.
거리(mm)                 0       29.24       58.48
센서 1 (PA0) ADC         0       522         4095
센서 2 (PA1) ADC         0       529         4095

가운데는 사용자와 합의한 실제 이동거리의 절반으로 해석했다.
실제 측정 위치가 30mm 등 다른 위치였다면 mm[1]을 실제 측정 거리로 변경해야 한다.
구간별 선형 보간: 시작~가운데와 가운데~끝을 각각 직선으로 환산한다.
이는 세 점을 맞추는 근사이며, 전체 범위 선형성/정밀도를 보증하지 않는다.
0~4095를 보정점에 허용하도록 변환 검증을 수정했다. 이전 20~4075 조건은
전기적 끝점 측정을 보정점으로 등록하지 못하게 했으므로 변환과 구동 판단을 분리했다.
센서 단선/전원 단락과 실제 끝점은 ADC 숫자만으로 구분할 수 없다.
LIVE의 raw<10 또는 raw>4085 정지 검사와 위치 한계 검사는 유지한다.
기존 MOVE의 1~57.48mm 제한도 유지한다. 전체 60cc 구동 검증은 별도다.

live_cfg.enable=false, 두 motor_sign=0: 자동 구동은 계속 차단됨.
confirmed=true는 실측점 입력 완료이며 모터 방향/부력/조립 검증 완료가 아니다.
모터 JOG 명령, RTOS 주기/태스크 구성, 핀맵, 프로젝트 빌드 설정은 변경하지 않는다.

확인 방법:
모터 전원 분리 -> CubeIDE에서 F5/Build -> 업로드 및 Run/Resume.
STOP 후 SENSOR: PA0의 raw와 pos_um(마이크로미터)을 확인한다.
MODE LIVE 5 / STATUS의 raw는 기존과 동일하며, 표시 형식은 변경하지 않았다.
손으로 10,20,40mm 등 추가 위치를 잡아 보간 오차와 왕복 재현성을 확인한다.
최종 앞뒤 모듈 배치가 바뀌면 센서와 축 매핑/방향/사용 범위를 재확인한다.
